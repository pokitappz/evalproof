How it works

1. Freeze

Point EvalProof at outputs you already have and the grader you already run: a Python function or a Promptfoo config. It never calls your application model.

2. Prove

You review a JSON contract per fixture. EvalProof generates mutations that break it, plus valid controls, and shows why each one is wrong.

3. Gate

Deterministic graders must catch every mutation. LLM graders get bounded sampling with exact confidence intervals, so a flaky judge is INCONCLUSIVE, not PASS.

Private by design

Fixtures, grader outputs and reports never leave your machine or CI runner. Reports load nothing remote and contain no telemetry. The only hosted piece is a license check that sees your license key and GitHub organization name.
